# Stempel Geotag Foto + Peta

Aplikasi web statis (satu file `index.html`) untuk menempelkan stempel geotag + peta satelit pada foto,
dan menanam metadata EXIF (GPS, tanggal/jam, zona waktu, deskripsi) yang sama dengan isian di stempel.
Latar halaman berupa animasi titik bintang yang ringan (bisa dimatikan lewat tombol di halaman).

Tanpa build, tanpa backend. Buka `index.html` atau aktifkan GitHub Pages (branch `main`, folder `/ (root)`).
