Stempel Geotag Foto + Peta

Stempel visual di gambar, plus metadata EXIF yang sama di dalam file.

1 · Foto

Jika foto punya GPS dan waktu EXIF, isian di bawah terisi otomatis. Metadata kamera asli (Make, Model, exposure) dipertahankan.

2 · Lokasi

Baris besar di stempel — pakai format "Kota, Provinsi, Indonesia". Otomatis terisi saat cari alamat/koordinat.

Alamat lengkap untuk persamaan metadata. Otomatis dicari dari internet (OpenStreetMap) berdasarkan koordinat paling dekat.

100 – 200 m

"Lokasi acak terdekat" membuat titik baru 100–200 m dari titik alamat yang dicari — tiap kandidat diuji online (reverse-geocode) supaya tetap di kecamatan yang sama dengan alamat terisi. Kalau kandidat keluar kecamatan (dekat batas), radius mengecil otomatis (50–100 → 20–50 → 5–20 m); kalau tetap gagal, koordinat tidak diubah. Berguna supaya setiap foto tidak berkoordinat persis sama.

3 · Waktu & Note

Catatan singkat kegiatan — akan tampil sebagai baris terakhir di stempel foto dan tersimpan di EXIF UserComment. Default: "Created by cam-stempel-GPS".

4 · Metadata Kamera

Metadata kamera dipakai supaya foto tidak terdeteksi sebagai hasil edit. Diisi otomatis dari EXIF asli bila ada.

5 · Hasil

Foto kecil bisa diperbesar (upscale) dan foto besar bisa diperkecil (downscale) — tinggi mengikuti otomatis (rasio asli dipertahankan). "Asli" = tanpa resize (maks 2000 px). Catatan: ini atur dimensi pixel. Untuk naikkan ukuran file di disk (mis. 130 KB → 750 KB), pakai mode "Naikkan ke ≈ target" di bawah. Upscale dimensi besar bisa terlihat agak lembut — gunakan seperlunya.

Urutan proses saat klik "Buat geotag": (1) foto di-resize ke lebar target di atas (bisa perbesar/perkecil), (2) stempel geotag digambar, (3) ukuran file diproses sesuai mode: batas atas (kompresi kualitas+dimensi sampai di bawah target) / Naikkan ke ≈ target (kualitas & dimensi dinaikkan utk mendekati target bila foto asli lebih kecil — mis. 130 KB → ≈ 750 KB) / Tanpa batas (kualitas penuh).

Klik "Buat geotag" untuk menerapkan & mempratinjau metadata sesuai form saat ini (alamat, koordinat, tanggal-jam, note, kamera) — panel di bawah menampilkan metadata yang akan tertanam termasuk ukuran file hasil kompresi. Setelah cocok, klik "Download JPG + EXIF" untuk menyimpan.

Tekan tombol di bawah untuk mengunci aplikasi. Password wajib dimasukkan lagi untuk membuka.

Generate Versi Distribusi (untuk GitHub)

Tombol ini menghasilkan file index.html baru dgn password admin + semua Kode Akses TERTANAM (terenkripsi). Upload hasilnya ke GitHub. Orang lain hanya bisa masuk dgn kode akses dari Anda — tidak ada halaman buat-password utk mereka.

Cara pakai:
1. Buat kode akses utk tiap orang di section di atas (salin & kirim ke orangnya)
2. Klik tombol di bawah → download index.html (versi distribusi)
3. Upload ke GitHub repo (replace index.html lama)
4. Kirim link GitHub + kode akses masing-masing ke user
5. User buka link → masukkan kodenya → pakai app

Tambah / cabut kode: buka file ASLI (sebelum publish, simpan baik-baik) di komputer Anda, tambah atau cabut kode, lalu generate ulang & upload ulang. Kode lama yang dicabut berhenti berlaku setelah file baru terpasang.

⚠️ File hasil memuat token terenkripsi (AES-GCM, PBKDF2 100k) + nama penerima kode (terlihat jika file dibaca) — pakai nama panggilan saja. Pakai password admin yang kuat (min 12 karakter). Ini aplikasi statis tanpa server, jadi pembatasan bersifat sisi-klien.
